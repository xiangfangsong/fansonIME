# 放松输入法（fansonIME）设计

状态：0.1.6 已获用户验收，已统一中文及英文候选的直接选择行为，通过 Debug 编译、62 项单元测试、54 项模拟器检查和零问题 Lint，已覆盖安装真机。0.1.4 功能已获用户验收。日期：2026-11-08。实际功能及验证以 [README](../README.md)、[版本记录](CHANGELOG.md) 和版本验证记录为准。未来可加入用于偶尔输入的离线拼音，本次不实现。

## 0.1.6 简繁、离线英文补全与候选选择

- 中文与英文统一为点击可见候选立即上屏，无论候选是否溢出；中文提交选中字词，英文只替换当前预编辑词。点击候选不打开展开页。
- 只有点击右侧向下箭头才展开；展开页中的候选也可直接选择。候选仍按实际宽度测量，仅在一行放不下时显示箭头，不支持横向滑动。
- 本轮修复继续归入 0.1.6；应用名称、关于、安装包和版本文档统一使用该版本。内部构建编号递增以便覆盖安装时保留数据，不增加对外版本。
- 验证简体、繁体、英文溢出行直接选择、箭头展开及收起、展开选词和一行全部容纳时无箭头；沿用原模拟器，覆盖安装真机前告知。

- 五笔主键盘底行原“中/英”按钮改为“简 / 繁”，表示当前输出状态，默认简体。点击立即刷新未完成编码的候选，不提交编码；左上角继续负责五笔与英文切换。简繁状态在当前服务中保留，重启默认简体。
- 简体沿用原词库；繁体使用离线内置、固定版本的 OpenCC 字符及词组映射。词组按最长匹配消歧（头发、发展）；单字保留映射表的全部繁体选择（发→發、髮），按上游顺序稳定去重。词组保留所有明确映射结果，不穷举脱离语境的逐字组合。未收录字符原样保留，自定义短语也转换。
- 转换在候选进入引擎时完成，点击、空格、标点、切面板、第五码和四码自动上屏均使用同一结果。精确候选扩展为多个繁体结果后，不再触发“四码唯一”自动提交。去重保留原码及精确/补全身份。
- 英文模式该按钮使用本地矢量“Aa + 勾”图标表示开启，“Aa + 横线”表示关闭，无中文 caption；提供中文无障碍名称和选中状态。默认开启前缀补全，点击关闭；密码框强制禁用，不展示词表。状态在当前服务中保留。
- 内置有明确许可、固定校验值的英文常用词表，按词频稳定排序，每个前缀最多返回 80 个词。输入字母实时显示前缀匹配词，完整词优先；大小写跟随实际前缀（小写、首字母大写、全大写）。英文候选不附五笔编码，复用单行测量、仅溢出显示向下箭头、无横滑、展开页选词规则。
- 英文开启补全时使用 Android composing 文本显示原始字母，点击候选只替换当前词。空格提交原词并加空格，不自动把 app 改成其他词；回车有当前词时先提交原词，下一次执行换行/发送。标点和模式/面板切换先提交原词；关闭开关也先提交原词。无匹配仍可输入原词，退格先删当前词，移动光标或选择文字结束补全，切换输入框清空临时状态。关闭补全时逐字上屏。
- 英文词表后台加载后，内存索引查询、英文输入状态及 composing 编辑在主线程按同一操作同步执行，避免快速跨单词输入时被迟到的编辑器回调截断；五笔 SQLite 查询继续使用后台串行线程。必要时只请求光标周围 0 个字符的位置信息判断过期回调，不读取全文。
- 不学习或保存英文输入，不读取全文预测、不联网。Emoji 五笔搜索继续用简体关键词，回主键盘恢复简繁选择；辅助页面候选隐藏规则保持。
- 验证一简多繁、词组消歧、自定义短语、实时切换与四码歧义保护；英文前缀、大小写、无匹配、退格、原词提交、开关、光标及会话隔离；共用候选溢出和原有功能回归。先在原模拟器验证 Debug，覆盖安装真机前告知用户。

## 0.1.5 候选区显示范围

- 用户已验收 0.1.4 功能，本轮只收敛候选区的显示范围。
- 主键盘输入时显示编码提示与候选栏；进入剪贴板、emoji 浏览、符号、数字页面时，两者同时隐藏并移除占位，工具栏下直接呈现面板内容。
- 返回主键盘时恢复编码提示与候选栏，沿用原有单行测量、溢出展开及选字规则。
- Emoji 的五笔关键词搜索会调出输入键盘，此时仍显示编码与候选供组成搜索词；退出搜索、返回 emoji 浏览时立即隐藏。仅浏览和点击表情时不显示候选区。
- 沿用现有面板切换时处理未完成编码的规则；隐藏视图不清空输入数据，也不改变剪贴板及 emoji 使用记录。
- 验证主键盘与各面板间切换的可见性及空间释放、emoji 搜索选字、原有输入功能。继续使用项目原模拟器；真机覆盖安装前先告知。

## 0.1.4 Emoji 与符号修订

### Emoji

- 移除“收藏”分类、收藏数据及相关操作，不再提供 emoji 长按弹层或长按后的动态重绘，避免该操作引发频闪。
- “常用”改为本地使用频率排序：只统计用户从 emoji 面板成功插入的完整 emoji 序列，次数高的在前；同次数按最近使用顺序排序，再按默认种子顺序稳定补位。
- 常用最多 30 项，固定为一页，不显示翻页箭头或页码；无使用记录时以默认常用集合补齐。其他分类和搜索仍可翻页。
- 统计所有实际用过的支持序列，包括来自旗帜等分类、搜索或肤色变体的输入；常用不局限于原先固定的笑脸名单。先过滤设备不支持的字形，再填满这一页。
- 一次插入成功只增加一次计数，长按不打开菜单、不连发。当前页面不在手指操作后立即重排，重新进入“常用”时按最新频率刷新，避免按钮突然换位。
- 取消长按肤色菜单后，将肤色等变体直接放入人物分类及中文关键词搜索结果，仍一次提交完整序列。
- 只保存 emoji 的累计次数和最近使用顺序编号，不记录日期、输入正文或应用名；保存在无备份私有目录。隐私输入会话不更新次数。设置页提供清除相应本地数据的入口。

### 符号

- 点击工具栏符号图标，每次默认进入“常用”分类。分类顺序固定为：常用、中文、英文、箭头、数学、序号、单位、货币、括号、图形、希腊、制表。
- 常用收录日常标点及常见特殊符号；中文含全角标点、书名号、引号、破折号、省略号等；英文完整覆盖美式 PC 键盘 32 个可打印标点，不再遗漏反引号、美元、冒号、引号等。
- 箭头、数学、序号、单位等使用离线内置的明确字符表。多字符符号（如省略号、破折号、单位）作为完整条目一次输入，不以空格拆碎。
- 符号面板采用左侧类别、右侧符号网格，首屏按键区容纳 4 个完整行（计入按键间距）；类别和符号区域可纵向滚动但不显示滚动条。点击符号后留在当前分类，方便连续输入。
- 所有符号与分类均固定顺序，不记录符号使用频率、不自动置顶。返回键盘、退格、空格和回车等基本操作保留。

分类方式参考搜狗输入法企业版公开“符号输入”文档中按标点、序号、数学/单位、语言字符、制表等用途组织的方式；本项目的字符表与布局独立编排并离线内置。

参考：[搜狗输入法企业版符号输入（腾讯云官方文档 PDF）](https://main.qcloudimg.com/raw/document/product/pdf/1655_81582_cn.pdf)。

验收覆盖：移除收藏及长按菜单、常用单页与排序/上限/补位/本地持久化、实际输入计数、符号默认分类与分类切换、英文标点完整性、特殊符号完整插入、固定顺序，以及原有候选栏、回车、Shift、剪贴板回归。沿用项目原模拟器，更新真机前先告知用户。

## 0.1.3 候选栏与 emoji 修订

- 候选栏固定一行，移除横向滚动容器；不允许通过左右滑动找候选。
- 根据候选文字、实际字号、内边距、间距和键盘可用宽度测量是否能完整放下一行。无候选或全部候选能放下时，不显示展开按钮，允许直接点击候选上屏。
- 放不下时，右侧保留向下箭头图标；行内呈现能容纳的候选，其余候选在展开页呈现。按 0.1.6 修订规则，点击行内候选直接上屏，仅箭头用于展开。原有空格选首选规则保持。
- 展开页提供全部当前候选和向上箭头收起。只有一个候选也按实际宽度判断：普通单项不显示箭头，单项超长无法完整显示时仍可展开查看并选择。
- 输入编码、候选或屏幕宽度变化时重新测量；旋转、字体缩放后不沿用旧的溢出判断。
- Emoji 分类栏继续允许左右滑动，但禁用水平、垂直滚动条及边缘渐隐、弹性边缘效果。
- 点击“旗帜”等分类、翻页、收藏操作引发面板重绘时，保留分类栏原来的水平偏移，不跳回最左边，不主动将选中项移到另一位置。离开 emoji 面板或切换输入框后可重置为初始位置。

验收覆盖：无候选、单项、多个但一行可容纳、溢出、超长单项、宽度变化、展开选字/收起、候选栏不可横滑，以及 emoji 分类滚动条关闭、右侧分类选择后偏移保持和原有输入回归。继续使用项目原模拟器；更新真机前先告知用户。

| 主工具栏 | 依次为模式、剪贴板图标、符号图标、emoji 图标、设置图标、向下小三角；向下三角位于设置右侧，点击收起键盘 |

本轮不调整码表、候选排序、四码自动上屏、剪贴板历史或 emoji 数据。自动四码上屏已经发生时，回车不会撤回已提交的字词。

## 1. 产品目标与默认取舍

做一款安装到自己手机、可在各应用中使用的 Android 系统输入法：86 版五笔为主，英文、数字、标点和 Unicode emoji 为辅，安装后所有输入功能都能离线工作。

- 原生 Kotlin 开发；先做好软键盘，后续再完善外接键盘。
- 最低支持 Android 12（API 31），即 `minSdk = 31`。编译和目标 SDK 在实施时按本机开发环境与官方要求确定，不与最低版本混为一谈。
- 默认简体、半角字母数字、中文标点、固定候选顺序。
- 默认不保存输入历史、不自动学习字词频率；按用户要求仅保存 emoji 使用次数和最近顺序用于常用排序，允许手动添加常用短语，不提供 emoji 收藏。
- 提供浅色、深色和跟随系统主题，优先保证按键准确、响应稳定。
- 首版范围：五笔86、英文、数字、符号、emoji、剪贴板查看与粘贴、一键清空剪贴板、基本设置、启用引导。
- 后续范围：拼音反查、自动调频、本地图片表情包、词库导入导出、单手模式。

开发电脑下载 SDK、依赖与词库属于构建过程；手机端安装包内置运行所需资源，首次启动也不下载数据。

## 2. 键盘界面

从上到下分为工具栏、编码与候选区、按键区。宽度随屏幕适配，横屏使用较低键盘；键高、底部留白可调。

```text
┌───────────────────────────────────┐
│ 五笔86     📋    #+    ☺    ⚙    ▾  │
│ 编码：……                          │
│ 候选1   候选2   候选3   候选4   ▾  │
├───────────────────────────────────┤
│ Q  W  E  R  T  Y  U  I  O  P       │
│  A  S  D  F  G  H  J  K  L         │
│ ⇧  Z  X  C  V  B  N  M       ⌫     │
│123   简    ，    空格    。    ↵    │
└───────────────────────────────────┘
```

- 候选固定单行、不可横向滚动；中文和英文的可见候选均直接点击上屏。只有实际放不下时出现向下箭头，点击箭头在网格页选字；一行全部放下时不显示展开按钮。
- 长按字母显示数字或常用符号；可选字根提示，默认隐藏。
- 长按空格进入光标移动；只按操作需要读取有限上下文。
- 回车在无编码时显示换行图标或对应的搜索、发送等编辑动作；存在五笔编码时只提交原始字母，防止误选字和误发送。
- 按键支持按下反馈、可选震动；默认不弹出显示敏感字符的放大预览。
- 主工具栏使用本地矢量功能图标，设置右侧以向下三角收起键盘；键盘不再单设“切换输入法”按钮。应用首页保留系统输入法选择入口，适配导航栏、安全区域、横竖屏和字体缩放。
- 显示状态使用“五笔86 / 英文 / 隐私模式”等简短文本，设置页展示离线与数据保存情况。

设置页分为输入习惯、键盘外观、emoji、隐私与数据、关于。首次打开引导用户进入系统页面启用并选择输入法，附带本地试打区。

### 剪贴板面板（首版）

工具栏常驻“剪贴板”入口。点击后将按键区切换为剪贴板面板，保留返回键盘按钮。

```text
┌───────────────────────────────────┐
│ ‹ 返回键盘    剪贴板    一键清空    │
├───────────────────────────────────┤
│ 当前内容                          │
│ 复制的文本……                      │
│ 可滚动查看，长文本可展开           │
│                                   │
│             [ 粘贴 ]              │
└───────────────────────────────────┘
```

- **查看**：打开面板时读取系统当前剪贴板并显示文本；面板可见期间监听变化并刷新。剪贴板为空时显示空状态，无权访问时明确提示，不能将访问失败当成“已清空”。
- **粘贴**：用户点击后，将显示的文本提交到当前输入框，不自动发送消息。五笔编码尚未结束时沿用 emoji 面板规则：先提交有效候选，无匹配则保留编码并提示修正。
- **一键清空**：调用 `ClipboardManager.clearPrimaryClip()` 并清除本输入法的全部剪贴板历史和临时预览；不增加二次确认，系统清除失败时明确区分本地历史清除结果。
- **读取时机**：默认输入法服务运行时监听剪贴板变化，包括键盘或面板隐藏时；销毁服务时注销，不做轮询。系统限制或服务不在运行时可能无法捕获记录，不能恢复此前的复制历史。
- **数据保存**：按用户要求，在无备份私有目录保存最近 10 项普通文本，重复复制置顶，超出上限淘汰最旧项，关闭键盘及重启保留；支持历史粘贴、单项删除及一键清空。锁屏、隐私输入会话和标记为敏感的内容不自动记录。所有内容不写日志、不上传。
- **敏感内容**：剪贴板标记为敏感，或当前为密码输入框时，默认遮住内容，允许用户主动点击“显示内容”或“粘贴”；不自动预览，也不禁止用户主动粘贴密码。
- **内容类型**：首版完整支持文本。图片、文件等仅提示类型，仍可一键清空；不自动读取 URI 指向的文件，不将 URI 路径当作正文粘贴。图片粘贴后续按目标应用富内容能力适配。
- **更新与一致性**：粘贴前检查当前剪贴板是否与面板内容一致；若已被替换则先刷新并提示用户重新选择，避免粘贴意外内容。大文本限制首屏预览量，按需展开，不在 UI 线程进行昂贵处理。

技术上使用系统 `ClipboardManager`，作为当前默认输入法按系统规则访问，不需要网络或无障碍权限。系统可能限制访问或主动清空内容，面板应同步反映实际状态。

“一键清空”清除当前 Android 用户/资料空间中的系统当前剪贴板、本输入法历史及临时预览，不代表清除其他输入法、应用或厂商服务自行保存的历史副本。

来源：[ClipboardManager 读取与清除接口](https://developer.android.com/reference/android/content/ClipboardManager)、[敏感剪贴板处理](https://developer.android.com/privacy-and-security/risks/secure-clipboard-handling)。

## 3. 五笔输入规则

| 操作或状态 | 默认行为 |
| --- | --- |
| 字母编码 | 按五笔86码表匹配，标准编码最长四码 |
| 一、二、三级简码 | 展示对应简码字词，空格或点击上屏 |
| 候选排序 | 精确编码候选优先；补全候选单独标识；保留码表内的固定顺序 |
| 空格 | 有候选时提交高亮候选；无编码时输入空格 |
| 四码唯一 | 有且仅有一个精确候选时自动上屏；可在设置中关闭 |
| 四码重码 | 保留候选等待选择；继续输入第五个有效编码键时，提交当前首选，再用该键开始下一段编码；此行为可关闭 |
| 无匹配编码 | 保留编码并提示，不自动丢码、不擅自提交字母；继续编码受四码上限约束 |
| 无候选时空格 | 保持原编码，允许退格修正；回车可明确提交原始字母 |
| 退格 | 优先删除一个编码字母；编码为空时删除输入框中的内容 |
| 编码中按标点 | 有候选时先提交高亮候选，再提交标点；无候选时保持编码并提示修正 |
| 编码中按回车 | 无论是否有候选，均只提交原始字母；下一次无编码回车才执行编辑器动作 |
| Shift | 五笔86 时提交未完成的原始编码并转英文大写；英文时在大写与小写之间切换，回五笔86使用模式切换按钮 |
| 切换应用或输入框 | 清空临时编码、候选和搜索状态，避免串入另一输入框 |

首版不默认启用联想、整句预测或拼音混输，避免改变五笔候选顺序。Z 键首版保留；后续可配置为离线拼音反查或通配查询，二者互斥。

常用短语通过设置页手动添加“编码 → 文本”。多字词生成编码时采用五笔86规则：两字取各前两码，三字取前两字首码及第三字前两码，四字及以上取前三字和末字首码。生成依据必须使用字的完整取码信息，不能直接拿一级简码拼接。

### 码表与词库

- 候选来源考虑 Rime 的 `wubi86.dict.yaml`，其仓库明确标注五笔86，码表可转换后独立使用；首版不需要嵌入完整 Rime 引擎。
- 已核对上游说明并集成固定 revision 的码表，保留原始文件、作者、许可和转换记录，详情见 THIRD_PARTY_NOTICES.md 与 resources.lock.json。
- 固定数据版本与 SHA-256，构建阶段转换、检查编码、去除重复项并生成索引；手机端不解析大份 YAML。
- 一级简码与首选顺序单独建立回归样本，防止不同码表的习惯差异。
- 词频字段使用 64 位整数；候选同时保存编码、文本、基础顺序和完整取码信息。

来源：[Rime 五笔仓库](https://github.com/rime/rime-wubi)、[码表](https://raw.githubusercontent.com/rime/rime-wubi/master/wubi86.dict.yaml)。

## 4. Emoji 与图片表情包

### 首版：Unicode emoji

- 内置 emoji 序列及中文名称、关键词数据，分类包括笑脸、人物、动物、食物、活动、物品、符号和旗帜。
- 不提供收藏或长按弹层；常用按本地使用频率排序且最多一页 30 项，其他类别与搜索保留分页。
- 肤色等变体在人物类别及搜索结果中直接选择，完整 Unicode 序列一次提交。
- 分类栏可横向滑动但不显示滚动条；同一 emoji 面板内切换分类或翻页重绘时保留原有水平位置。
- 面板内搜索框使用自己的临时输入状态，可用五笔输入中文关键词，搜索内容不会写进宿主应用。
- 主键盘编码未结束时点击 emoji：有候选则先提交高亮候选，再打开面板；无候选则保留编码并提示先修正或取消。
- 删除按可见字符簇处理，覆盖肤色修饰、旗帜、变体选择符和 ZWJ 序列；不能按一个 UTF-16 字符直接截断。对复杂序列结合内置数据和实际系统行为验证。
- 首版优先显示手机系统能渲染的 emoji，针对不支持的序列做隐藏或降级；发送后的外观取决于接收应用和对方设备。若后续需要统一面板外观，可内置字体，禁止依赖联网字体下载。

数据采用 Unicode emoji 序列与 CLDR 中文名称/关键词，固定版本并保留许可。数据存在不等于设备字体一定支持。

来源：[Unicode emoji 数据说明](https://www.unicode.org/emoji/charts/)、[CLDR 名称与关键词](https://cldr.unicode.org/translation/characters/short-names-and-keywords)。

### 后续：本地图片、GIF 表情包

通过系统文件选择器导入用户选择的图片，复制到应用私有目录，生成本地缩略图，不请求整个相册或全部文件权限。

根据目标输入框声明的 MIME 类型判断能否插入，通过 Commit Content API 和带临时读取授权的 content URI 提交。目标应用不支持时显示“当前应用不支持直接插入此类图片”，可由用户主动选择系统分享；不能承诺微信、QQ 等应用的所有输入场景都支持。

来源：[Android 图片键盘支持](https://developer.android.com/develop/ui/views/touch-and-input/image-keyboard)。

## 5. 隐私设计

| 范围 | 设计要求 |
| --- | --- |
| 网络 | 合并后的 Manifest 不含 `INTERNET`；无广告、统计、远程崩溃上报、在线字体或云词库依赖 |
| 权限 | 不索取通讯录、定位、麦克风、短信、无障碍或全盘存储权限；按需添加触感等与功能直接相关的普通权限 |
| 输入日志 | 调试版和发布版均禁止记录编码、候选、正文、密码和剪贴板内容 |
| 临时输入 | 仅保存在内存，输入会话结束、切换输入框时清空 |
| 本地数据 | 保存设置、手动短语、emoji 次数/最近顺序和最近 10 项剪贴板普通文本；使用无备份应用私有存储 |
| 自动学习 | 首版关闭；后续可选开启，只记录必要的词条选择计数，不保存整段输入历史 |
| 密码与隐私字段 | 识别文本、数字等密码变体；禁用学习、联想、历史、emoji 推荐和字符预览；遵循 `IME_FLAG_NO_PERSONALIZED_LEARNING` |
| 剪贴板 | 默认输入法服务监听复制变化，保存最近 10 项普通文本；敏感标记、锁屏及隐私输入不记录；支持单项删除，清空同时作用于当前内容和全部本地历史 |
| 系统备份 | 禁用应用自动备份，并配置对应 Android 版本的云备份、设备迁移排除规则，不能仅依赖 `allowBackup=false` |
| 对外组件 | IME 服务由 `BIND_INPUT_METHOD` 权限保护，其余组件按最小暴露原则配置；图片提供器仅授予所选文件的临时读权限 |
| 清除与导出 | 可清空短语、emoji 次数和剪贴板历史；导出仅由用户主动操作，并说明导出文件会包含哪些本地数据 |

“本输入法离线”指输入法自身不向服务器传输内容；提交给聊天、浏览器等目标应用后的数据由目标应用处理。这一边界在隐私说明中明确写出。

来源：[Android 权限参考](https://developer.android.com/reference/android/Manifest.permission#INTERNET)、[编辑器隐私标记](https://developer.android.com/reference/android/view/inputmethod/EditorInfo#IME_FLAG_NO_PERSONALIZED_LEARNING)、[系统备份与迁移规则](https://developer.android.com/identity/data/autobackup)。

## 6. 技术结构

先使用单个 Android app 模块，按包划分责任，避免个人项目过早拆成多个 Gradle 模块。

```text
app/
  ime/       FansonInputMethodService、InputConnection 适配、输入框类型识别
  engine/    WubiEngine、编码状态、精确匹配与补全、候选排序
  keyboard/  键盘 View、触摸事件、候选栏、数字与符号布局
  clipboard/ 系统剪贴板访问、变化监听、内容面板、粘贴与一键清空
  emoji/     分类面板、独立搜索状态、序列处理、单页常用排序
  data/      只读码表、用户短语、配置、emoji 次数、本地资源版本
  privacy/   敏感输入策略、日志约束、数据清除
  settings/  启用引导、偏好设置、试打区、关于
```

主要选择：

- 通过 `InputMethodService` 接入 Android，通过 `InputConnection` 管理组合文本、提交、删除及编辑动作。
- 键盘使用原生 View 与可复用按键组件；emoji、候选面板采用可回收列表。按键须提供无障碍标签与合理触摸区域。
- 五笔引擎使用纯 Kotlin，与 Android UI 分离，便于验证编码规则。
- 码表采用带编码索引的只读 SQLite；构建时生成数据库，安装后首次使用前复制到私有目录。先满足正确性和实测性能，再考虑 Trie 等替代结构。
- 精确编码查询和有界前缀查询分开；候选分页加载，不在主线程扫描整个词库。
- 设置、用户短语、emoji 次数及剪贴板历史统一使用无备份目录下的小型 SQLite 数据库，减少额外运行时依赖；移除旧收藏表。
- 候选查询结果携带会话标识与查询序号，只接收当前会话最新结果，防止快打时旧候选覆盖新候选。
- 输入事件串行处理；InputConnection 失效时停止提交，避免往失去焦点的输入框写入。
- 剪贴板访问封装为独立控制器，监听与面板生命周期绑定；区别空内容、不可访问、非文本和操作失败状态；应用内部搜索框与宿主输入框分别处理粘贴目标。
- 构建固定依赖版本，后续提供本地签名 APK；妥善保管个人签名密钥，以便覆盖升级。

来源：[Android 输入法开发指南](https://developer.android.com/develop/ui/views/touch-and-input/creating-input-method)。
