# 0.1.4 验证记录

日期：2026-11-08。

## 本版范围

- 移除收藏分类、收藏数据、emoji 长按弹层和长按收藏/肤色提示。肤色变体在人物分类与搜索中直接选择。
- 常用按本机使用次数降序，同次数按最近顺序降序，默认集合稳定补位；最多 30 项一页，无页码或翻页键。支持从其他分类及搜索使用的 emoji 进入常用。
- 只在输入连接接受 emoji 插入且不处于隐私输入时增加次数；不在当前网格中立即重排，重新进入常用时更新。只存次数与顺序编号，不存日期、正文或应用名。
- 新增 12 个固定符号分类：常用、中文、英文、箭头、数学、序号、单位、货币、括号、图形、希腊、制表。默认常用，所有条目固定顺序；英文完整覆盖 32 个可打印键盘标点。
- 符号类别及网格可分别纵向滚动，首屏容纳 4 个完整按键行；多字符符号整项插入。符号不参与 emoji 次数统计或自适应排序。

分类参考来源在 DESIGN.md 中列出；字符表和布局独立编排，所有数据离线内置。
