# 0.1.3 验证记录

日期：2026-11-08。

## 本版范围

- 候选使用固定单行视图，移除横向滚动容器。以实际文字测量宽度、字号、内边距和间距判断是否溢出。
- 全部候选放得下时无展开按钮，直接点选；放不下时才显示向下矢量箭头，行内预览只打开展开网格，由展开页选字。空格选首选保持不变。
- 普通单项不显示箭头；超长单项仍允许展开。输入或可用宽度变化重新判断，展开后可用向上箭头收起。
- Emoji 分类栏关闭两方向滚动条、边缘渐隐和弹性边缘效果。同一面板切换分类、翻页或收藏重绘时保留水平位置；不改分类、数据或输入规则。
