日期：2026-11-08。应用版本 0.2.0，内部构建编号 versionCode 13，Android 12+。按用户确认的方案实现离线查读音，已通过用户真机验收，用户已授权提交 Git。

## 本版行为

- 五笔键盘空闲按 Z 输入待上屏的 z；回车上屏、清码或保留无候选编码，遵循已有回车设置。英文正常输入 Z/z。
- 有候选时按 Z 切换五笔提示与读音，无候选时保留原编码并提示。精确与补全候选均显示读音，切换不改变候选排序及上屏文字。
- 候选内汉字在上、拼音在下，共用原有 44dp 顶部行。读音完整保留，可横滑；原有展开网格同步显示，不增加二级页面、弹窗、长按或开关。
- 查读音期间继续补码和退格保持，暂缓四码唯一和第五码自动上屏；选字、提交、清码、换会话后恢复原显示与自动上屏设置。
- 全部查读音操作使用本地只读数据库，无网络权限、无查询历史。

## 数据覆盖核查

- pinyin-data：44,440 个单字，保留全部已收录带调读音。
- phrase-pinyin-data：47,152 个词组，保留多个整词读法；使用已内置 OpenCC 映射补充 33,219 个繁体查询别名。
- 生成 `pronunciation.db`：3,100,672 字节。两项目的原始数据、README、许可、revision 和 SHA-256 均保留，可用 `python tools/prepare_pronunciation_data.py` 离线重建。
- 当前 70,391 个五笔单字中，41,467 字有读音，28,924 字未收录。缺失分布：基本区 16、扩展 A 797、扩展 B 28,087，其他 24；扩展 C～E 的现有单字均有记录。
- “行、重”显示全部已收录读法；“银行、銀行”均为 `yín háng`，“重庆、重慶”均为 `chóng qìng`。补充区字符按 Unicode 码点处理，例如 `𠀀` 有 `hē`；`𠮷` 在本资料中未收录，显示“暂无读音”。
- 未收录词组标明“逐字”，不穷举多音字组合。读音资料不保证包含所有汉字、历史或人名读法。
- 原五笔字库保持 SHA-256 `a42d340cb0e456ba96a348606778da443743abee13b536f80cd19af827925894`。
