# 0.4.2 同版本按键长按修正

状态：已实现，最终真机验收通过并获提交授权，未授权推送；基于尚未提交的 0.4.2 / 21，2026-11-11 用户反馈 L 字母被双行提示裁切，并确认新的数字/标点长按需求。保持版本和用户已有设置；用户于 2026-11-11 确认最终验收通过并授权提交，未授权推送。

## 方案与边界

- L 恢复普通单行 Button 的原始居中排版，灰色撇号独立绘制于右上角，不占正文行高；不新增其他字母快捷键。
- 主键盘顶部数字行开启时，三语数字 1234567890 长按映射美式 PC Shift 符号 !@#$%^&*()（半角）；数字短按不变。提示复用右上角形式，不挤动数字。
- 开启数字行时，中文逗号/句号长按分别为全角冒号与成对中文双引号，英语/韩语为半角冒号与单个直双引号。关闭数字行时保留原全角/半角叹号与问号。符号面板、独立数字页不改。
- 中文引号经现有 punct/enqueue 路径先确认候选、再提交 “”；仅会话有效、非搜索、所有 commits 被 InputConnection 接受且清码时执行 onCommitted。随后请求光标前 1 个字符核对右引号与实际绝对位置，用 setSelection 放在右引号前。无匹配、连接为空、提交拒绝、读不到位置或尾部被宿主改写时不擅自移动光标，不新增定时重试。
- 原五笔 worker 串行和英语/韩语主线程不变；内部 emoji 搜索只把符号写入关键词，不提交或移动宿主光标。无新权限、依赖、外部资源或数据迁移；原创代码继续遵循 Apache-2.0。
