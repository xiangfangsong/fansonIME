# 地球键快捷切换与默认语言

状态：已实现，真机验收通过；日期：2026-11-09；基于 0.3.1 / `5402efb`，本次版本 0.3.2 / 17。

## 问题与范围

地球键目前只有短按语言菜单，中英文切换需要两次选择。本次短按在当前非英语语言与英语之间往返，长按保留固定顺序语言菜单；设置增加默认语言，初始五笔86。默认语言可选现有三种语言，不新增引擎。

## 当前实现

服务 `chooseLanguage()` 经 `resolveThen()` 确认输入，清码后失效会话、保存 `input_language`、返回主键盘。`EditorPolicy` 对密码、邮箱、网址、数字字段临时覆盖英语。五笔 Shift 另有提交原编码并进入英文大写的入口。语言菜单和当前语言设置见 [界面](../UI_AND_PANELS.md)、[数据](../DATA_AND_PRIVACY.md)。

## 实现方案与取舍

- 以 `LanguagePreferences` 集中管理已有 `input_language` 与新增 `default_language`、`last_non_english_language`；通过 `LocalStore.putAll()` 在同一 SQLite 事务保存关联键，仍存入现有 preferences 表，不改表、不迁移或清除数据。
- 非英语短按切英语，同时记住离开的语言；英语短按优先返回最近非英语语言，无记录则用默认语言。默认语言本身为英语且无记录时回退五笔，避免短按没有效果。未知设置值安全回退。
- 默认语言初始五笔。设置修改时更新起始语言并重设非英语回切目标；日常新输入框沿用上次主动语言，系统字段覆盖不写回偏好。已有安装保留 `input_language`，无新键时从默认值平滑读取。
- 语言偏好只在实际切换成功后更新。短按和菜单共用 `chooseLanguage()`，不新增宿主提交路径；五笔无匹配不能切换，也不能修改回切记忆。英文/韩语确认预编辑后再切换；emoji 搜索先确认至内部搜索目标，随后切换回主键盘。
- 长按使用 Android `OnLongClickListener` 并返回 true；打开、取消、选择当前菜单项不确认输入，松手不触发短按。地球保持现有布局与无障碍名称，状态说明包含短按目标和长按菜单提示。
- 五笔 Shift 保留提交原编码及进入英文大写的旧行为，但记录五笔作为回切目标。

线程、FIFO、session 失效协议沿用现有实现。新偏好不包含输入内容，权限、备份、词库、签名与应用 ID 不变。

## 验证与验收

通过隔离模拟器检查默认值、旧偏好与未知值、设置选择及重开保存；五笔/英语、韩语/英语反复短按；英语起始回退默认语言；长按真实 DOWN/保持/UP 只开菜单；有候选确认一次、无匹配不改语言/记忆；英文/韩语 composing、字段覆盖、Shift 和内部搜索隔离。完整运行既有构建、单元测试、Lint 与仪器回归，保留原 AVD。

## 实施结果

已按上述方案实施，新增语言偏好管理与原子设置写入，服务和设置共用；未改引擎规则、表结构、应用身份或权限。103 项 JVM 测试、100 项完整模拟器检查及零问题 Lint 通过；真实触摸测试补充坐标稳定等待，普通菜单语义用独立长按回调检查。已提前告知并覆盖安装真机，用户确认验收通过并授权提交，未推送。完整命令、失败轮次、产物与设备证据见 [0.3.2 验证记录](../../validation/VALIDATION-0.3.2.md)；稳定规则已归入界面、输入链路、架构、数据和开发章节。
