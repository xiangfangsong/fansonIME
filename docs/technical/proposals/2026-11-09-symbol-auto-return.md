# 符号输入后返回键盘

状态：已实现，真机验收通过；日期：2026-11-09；基于 0.3.2 / `e71c76e`，本次版本 0.3.3 / 18。

## 问题与范围

符号页通常只需输入一个符号。新增“输入符号后返回键盘”开关，位于输入习惯，默认开启；开启时选择符号后回到原语言主键盘，关闭时保留符号页与分类。emoji 连续输入、符号页空格/退格/回车和主键盘标点保持。

## 实现方案

- 设置键 `symbol_auto_return` 存于现有 preferences 表，默认 true，无表结构迁移，旧安装自然启用。沿用设置在输入会话开始/显示时读取的规则。
- `SymbolPanel` 仍只回调完整字符串，服务符号选择入口复用 `punct()` 和 `enqueue()`。给 enqueue 增加可选提交完成通知，只有非搜索目标、确有 commits、所有 `commitText()` 均返回 true 且编码为空时通知。
- 符号入口在通知后检查开关及当前仍为 symbols，再改为 keyboard 并刷新候选/body；不再次 resolve，不失效会话，也不丢弃排队中的输入。既有 after 回调语义保持，session 校验继续拒绝过期结果。
- 不把返回逻辑放进 SymbolPanel 或通用 punct 的所有调用，不修改 emoji 点击路径。平台返回 true 代表提交调用被接受，不等于已验证任意宿主实际落字；G01 的回滚与重放限制仍存在。

## 验证与验收

在原隔离模拟器验证默认开启、三语言返回且语言不变、多字符符号完整输入、分类/空格/退格/回车不触发返回、关闭后连续输入并保持分类、重新打开开关生效及持久化、emoji 在两种开关状态下均可连续输入。运行构建、单元测试、Lint 与完整仪器回归，真机安装前告知，验收通过后按授权提交。
