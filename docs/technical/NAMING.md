# 命名与兼容性约定

自 2026-11-09 起，项目英文名称统一为 **FansonIME**。中文名称仍为“放松输入法”。命名整理基于 0.3.0 完成，只调整显示和工程标识，不因此修改输入规则或用户数据格式；随后 0.3.1 的功能与版本变更另见 [当前验证记录](../VALIDATION-0.3.1.md)。

## 现行名称

| 位置 | 约定 |
| --- | --- |
| 文档标题、正文、项目说明 | `FansonIME` |
| Gradle `rootProject.name` | `FansonIME`，不要求工作目录同步更名 |
| 应用关于页 | `放松输入法 · FansonIME` 加当前安装包版本；由 `PackageManager` 读取，避免版本常量内联后出现旧显示 |
| 桌面和系统输入法列表 | 保留中文“放松输入法”，来自 `app_name/ime_name` |
| 新建测试 AVD 的显示名称 | `FansonIME Android 12 Test`；已有 AVD 不迁移或重建 |
| 数据下载工具 User-Agent | `FansonIME-build/0.1`，不改变上游 URL、revision 或数据 |
| 今后归档的 APK | `dist/FansonIME-<版本>-debug.apk`；Gradle 默认输出仍为 `app-debug.apk` |

## 保留的兼容标识与历史值

| 标识 | 保留原因 |
| --- | --- |
| `com.fanson.ime`、对应 Kotlin 包和源码目录 | Android 应用身份及代码命名空间；改应用 ID 会成为另一应用，无法直接沿用原有升级与私有数据 |
| `FansonInputMethodService`、Activity、测试 runner 的组件名 | 已注册 IME 与工具脚本依赖组件身份；现有类名本身已符合首字母大写规范 |
| `fonts/fanson_wubi_roots.ttf` 等小写资源/数据路径 | 内部文件键；不作为品牌文字显示，不为大小写改名引入路径与哈希变动 |
| `personal.db`、设置键、哈希命名字典 | 现有持久化协议，本次不做迁移 |
| `fansonIME_API31`、原 `.local/avd/` 路径及 ini 文件名 | 复用用户要求保留的测试 AVD；显示名称与实例 ID 可不同 |
| 旧 `dist/fansonIME-…apk` 文件名及旧验证记录 | 指向真实历史产物；不因更名重写历史路径、大小和 SHA-256 |
| 字根字体内 2026-11-08 的 `fansonIME` 修改声明及生成脚本的对应字面量 | 是已分发字体的历史元数据；保留生成器原声明以复现当前字体，不为品牌大小写重建字库/字体 |
| 工作目录 `fansonIME` | 用户允许保留；命令使用相对路径或计算项目根目录 |

项目自写的许可说明正文使用新名称；第三方版权与许可原文保持原样。字根字体专用族名仍为 `Fanson Wubi Roots`。

## 维护和核对

修改名称时先辨别展示文本、兼容标识、历史证据和第三方原文；搜索到旧写法不意味着都应替换。不要改应用 ID、签名、IME 组件、偏好键或数据目录来实现品牌更名。

本次涉及 Gradle 根工程名、关于页、工具显示文字和项目自写许可说明；运行时引擎、Manifest 和用户数据协议不变。更名后的构建与校验结果追加到 [0.3.0 验证记录](../VALIDATION-0.3.0.md)，原 APK 记录继续表示旧产物。
