## 交互规则

| 键 | 顶部数字行开启 | 顶部数字行关闭 |
| --- | --- | --- |
| 1 2 3 4 5 6 7 8 9 0 | 中文为 ！ @ # $ % ^ & * （ ）；英语/韩语为 ! @ # $ % ^ & * ( ) | 该行隐藏 |
| 中文逗号 / 句号 | 短按 ， / 。；长按 ： / ？ | 短按不变；长按 ！ / ？ |
| 中文简/繁 | 短按原简繁切换；右上角提示“”，长按成对引号并定位中间 | 相同，与数字行无关 |
| 英语、韩语逗号 / 句号 | 短按 , / .；长按 : / ? | 短按不变；长按 ! / ? |
| 英语拼写 / 韩语 한/漢 | 右上角提示并长按输入单个直双引号；短按仍为拼写切换 / 无操作 | 无引号提示和长按；英语保留拼写切换，韩语禁用 |
| 英语 L/l | 短按字母、长按 ASCII 撇号；右上角灰色提示 | 相同 |

数字长按以美式 PC 顶部数字行 Shift 为基础，中文仅 1/9/0 按用户要求覆盖为全角叹号与左右括号，其余数字符号和英语/韩语保持原映射；不自动成对插入括号。独立 123 数字页及符号网格保持原有规则。三语共用既有 number_row 偏好，默认 true，没有新增设置键、schema、依赖、权限或第三方内容。英语句首大写与候选规则不因本修订改变。

中文长按简/繁每次明确插入一对左右双引号，并将光标放在右引号前，例如 光标→“|”，甲|乙→甲“|”乙，选区替换后也在新引号中间；不是基于全文计数交替单个左右引号，也不新增跳过已存在右引号的规则。后续正常输入走既有五笔链路，工上屏后得到“工|”。

## 提示布局与裁切修复

第一次 0.4.2 包把 L 复用了标点双行 SpannableString，L 与小提示分享行高，真机出现半字裁切。不得只缩小 L、挪动 L 基线或提高整个键盘高度掩盖问题。

`CornerHintButton` 继承原生 Button，主文本为单行原字母/数字；Ui.styleButton 复用普通按钮的字体、背景、padding、gravity 和点击初始化。灰色提示在 onDraw 调用 super 后，用独立 Paint 绘制于右上角：10sp、右对齐、距顶部 3dp，右侧在原 padding 外再留 3dp。不向 text 塞换行，不占主文本布局宽高，不创建可拦截触摸的叠加子 View。提示颜色来自主题 muted，无背景/行高额外变化。

`Ui.cornerHintButton` 共用于英语 L、顶部数字键及三语左侧功能键，设置 maxLines=1、stateDescription=长按输入…、OnLongClickListener 返回 true。`Ui.iconButton` 可选角标复用同一入口，并保留原图标、强调色和短按动作；强调色按钮的提示使用 accentInk，其余使用 muted，避免英语拼写开启时提示与背景对比不足。短按标签/无障碍定位仍为主字符，真实长按和松手由系统 Button 消费，不追加一次主字符，不新增定时任务。`Ui.punctuationButton` 仍用于底部逗号和句号，沿用原上提示、下标点布局。

验证以 40dp 最小键高、36dp 单键宽、1.0/1.3 字体倍数、深浅主题比较 L/l、简/繁与普通按钮基线、layout.height、单行及无省略，防止重现半字。截图另外核对真实键盘。未宣称所有极端字体比例和全部手机均已通过，本次原真机验收已获用户确认；不能扩大为全部字体比例或型号已验证。

## 输入与光标职责

- `KeyboardShortcuts` 为纯 Kotlin 映射，集中定义 10 数字（含中文 1/9/0 覆盖）和两种数字行状态下的逗号长按；句号长按始终是问号，仅按语言区分全半角，不再接收数字行参数。
- 英语/韩语左侧功能键仅在数字行显示时提供直双引号，调用 `keyboardPunctuation` 确认当前预编辑后插入单个引号，光标留在引号后。韩语只开放长按，短按的汉字转换仍未实现。英语长按不切换拼写；密码框数字行开启时仍可长按引号，但短按不能启用拼写，关闭数字行则保持原禁用状态。
- 服务 renderKeyboard 按 showNumberRow 决定显示和替代符号；number_row 在既有输入生命周期读取，设置变更后重新显示键盘生效。普通数字/符号复用 punct，不另建编辑链路。
- 简/繁角标复用原普通按钮的 16sp、padding、gravity、短按切换及无障碍名称，不向主文字添加换行。长按调用 `keyboardPunctuation(QUOTE_PAIR)`，不会切换简繁；数字行隐藏时同样生效。`keyboardPunctuation` 仅对中文成对引号附 onCommitted 回调；仍先由引擎处理当前词。五笔有候选先提交候选，无码直接提交引号，无匹配则保留编码与原光标；英文和韩语长按符号先确认预编辑。
- onCommitted 既有契约要求非搜索、确有 commits、全部提交返回 true、code 为空，且发布前 session 检查有效。仅在这些条件下调用 `PairedQuoteCursor.moveInside`；不提前对尚未上屏的字符计算旧光标。
- PairedQuoteCursor 请求 getSurroundingText(1,0,0)，核对选区已折叠、offset 非负、光标前最后字符实际为右引号。目标为 offset + selectionStart - 1（UTF-16 绝对下标），带边界/溢出检查，再调用 setSelection。支持前文包含代理对、正文中间、选区被替换和候选长度不同。
- 读不到位置、宿主尾部被改写/拒绝提交时保守保留当前光标，不发送方向键猜位置，不重试，不读取全文或保存周边字符。setSelection 也可能被特殊宿主拒绝；其返回不等于所有应用都支持光标内移，需实际验收。既有提交失败回滚缺口 G01 不由本功能解决。
- 五笔内部 emoji 搜索只追加符号到 emojiQuery，因非正文提交不执行光标回调。搜索内追加一对引号但没有内部中间光标，宿主正文/光标保持；不能为了支持引号把搜索输入写入宿主。

五笔继续在 worker 串行，引号移动在原结果发布的主线程回调执行，不丢弃中间正文提交，不改 session 或语言切换规则。符号网格自动返回、五笔学习成功反馈、原词提交与字符簇删除均保留。
