# 界面与面板

基线见 [入口](README.md)。当前界面通过原生 `LinearLayout/GridLayout/ScrollView/Button` 程序化创建。大部分布局在服务内构建，不采用 XML 键盘、Compose 或 RecyclerView。

## 渲染入口与状态归属

| 入口/组件 | 职责 |
| --- | --- |
| `render()` | 重建顶部和 body，关闭弹层、取消连删，保留 emoji 分类横向位置后重绘 |
| `renderCandidates()` | 根据输入状态切换候选/工具栏，提交候选快照，更新 Z 键状态 |
| `renderBody()` | 重建内容；有展开候选时优先渲染网格，否则依据 panel 渲染 |
| `Ui` / `Palette` | dp、布局、按钮、标点长按键、矢量图标、颜色及主题；提交动作由回调交给服务 |
| `CandidateStrip` / `CandidateRowLayout` | 实际 View 测量/布局与可 JVM 测试的宽度规划算法 |
| `SymbolPanel` / `SymbolCatalog` | 固定符号分类与网格；通过回调提交完整符号字符串 |
| `LanguagePopup` / `WubiRootCard` | 语言选择与字根查看弹层；只回调业务动作或展示数据 |

服务持有 `panel`（`keyboard/numbers/symbols/emoji/clipboard`）、`expanded`、语言、搜索词、emoji 分类/页码、剪贴板显示状态等。`expanded` 是覆盖当前 body 的显示标志，不是第六种 panel。光标控制直接替换 body，也没有独立 panel 值。

## 固定顶部行

顶部固定 44dp：地球始终占左侧，右侧在工具栏和 `CandidateStrip` 之间切换。候选显示条件完整表达为：

```kotlin
val inputPanel = panel == "keyboard" || (panel == "emoji" && emojiSearching)
val showCandidates = inputPanel && currentCode.isNotEmpty() && !password &&
    (chinese || (english && spelling))
```

有无匹配不改变候选区域是否显示：非空编码无候选时显示修正提示。宿主正文是否为空也不影响此条件。韩语、英文直输、密码及纯辅助面板显示工具栏；emoji 五笔搜索非空编码时例外显示候选。新增面板时要明确它是否属于 `inputPanel`，不能仅隐藏候选内容而保留空白行。

当前结构是根节点内 header＋body；header 内 globe＋toolbar＋candidateRow，二者通过 `GONE/VISIBLE` 互斥。`SmokeInstrumentation.checkCandidateArea()` 会验证结构、44dp 高度和相邻位置，结构重构需同步调整有意义的断言。

## 地球键与默认语言（0.3.2）

地球短按调用 `LanguagePreferences.quickSwitchTarget()` 后共用 `chooseLanguage()`：非英语进入英语，英语优先回到最近非英语语言；无记录使用默认语言，默认也是英语时回退五笔。五笔、韩语可分别与英语往返；长按才打开固定顺序菜单，监听器返回 true，松手不再短按。无障碍名称仍为“切换语言”，状态说明包含当前语言、短按目标及长按提示。

`chooseLanguage()` 仍先 `resolveThen()`，成功清码后才通过 `LanguagePreferences` 保存当前语言和回切目标，失效会话并返回主键盘。无匹配五笔阻止切换和偏好更新；英文/韩语先确认 composing。内部搜索先 resolve 到 `emojiQuery`，不写宿主正文。五笔 Shift 进入英文大写时也记住五笔回切目标。

设置“输入习惯”新增“默认语言”，可选 English、五笔86、한국어，初始五笔86。修改后下次进入输入会话从所选语言开始并重设回切目标；日常新输入框仍沿用上次主动语言，已有安装保留原 `input_language`。仅打开设置或重建页面不会覆盖当前语言。字段临时使用英语/数字页的规则保持，不写回语言偏好。

## 候选测量、选择与展开

普通模式先测量每个候选按钮自然宽度；编码提示最多 120dp，且不超过当前候选条宽度的 30%。剩余区域交给 `CandidateRowLayout.plan()`：

1. 所有候选和间距能放下时，不预留箭头空间。
2. 放不下时预留至多 44dp 的箭头与间距，按顺序放完整候选，不横向滚动。
3. 第一项本身过长时使用剩余槽位显示省略文本；仍可点选原候选。

候选按钮直接选择，只有独立箭头展开/收起。普通展开网格三列，单元高 52dp，使用同一 `candidateSnapshot`。刷新输入会清除 `expanded`；若重新测量已不溢出，则通过延迟回调自动收起。该回调用 `revision`、当前溢出值和 attached 状态拒绝旧布局通知，避免在 `onMeasure()` 中直接递归重绘。

读音模式复用 44dp 高度，按钮内部两行显示“候选文字＋12sp 读音”。候选行使用横向 ScrollView，保留全部读音；溢出仍显示展开箭头。展开网格改两列，格内允许横向滚动。普通模式的无横滑/省略规则不能直接复用于读音模式。

[`candidateButton()`](../../app/src/main/java/com/fanson/ime/keyboard/CandidateButton.kt) 仅组织显示和无障碍文字；实际选择交给服务重新验证。读音模式对显示文字做空白归一化，提交仍用原 `Candidate.text`。

## 面板切换与输入目标

`switchPanel(next)` 先 `resolveThen()`，成功后清理剪贴板快照、搜索词/搜索开关/分页及展开标志，再切换。重复点同一面板返回主键盘。五笔无候选会阻止切换，保留编码；英文/韩语先确认当前预编辑。打开设置与长按空格光标控制也先 resolve。

| 面板 | 输入路径与局部状态 |
| --- | --- |
| 主键盘 | 字母进入当前引擎，数字行调用 `punct()`；简繁只用于五笔，拼写只用于英文；韩语“한/漢”短按未开放，数字行开启时允许引号长按 |
| 数字 | 数字/运算符/下划线通过 `punct()`；返回不改语言，布局独立于主键盘数字行 |
| 符号 | 每次创建默认“常用”；分类条保留实例，切类只替换固定顺序网格，完整字符串经 `insertSymbol()` 复用 `punct()`；默认提交后回主键盘，可在设置关闭 |
| emoji 浏览 | 根据类别/搜索/字形过滤后取页面；点击完整序列直接插入宿主 |
| emoji 搜索 | 仅五笔提供入口；`emojiSearching=true` 时复用键盘与引擎，普通提交写入 `emojiQuery`，而不是宿主正文 |
| 剪贴板 | 读取快照和本地历史；当前值粘贴前再读，历史值直接选取；通过 resolve 后提交宿主 |
| 光标控制 | 长按空格先确认输入，再显示方向键；发 DPAD down/up，不读取全文 |

### 输入符号后返回键盘（0.3.3）

设置“输入习惯 → 输入符号后返回键盘”默认开启。`SymbolPanel` 的选择回调交给服务 `insertSymbol()`，复用 `punct()` 与 `enqueue()`；只有非搜索提交、确有 commits、全部 `commitText()` 返回 true 且编码为空，才执行 `onCommitted` 通知。服务确认当前仍在 symbols 且开关开启后，直接将 panel 改为 keyboard，刷新候选/body；保留语言，不额外 resolve 或失效会话。

关闭开关时提交后保留符号页和当前分类，可连续输入；再次打开符号页仍默认“常用”。开关沿用输入会话开始/显示时读取的规则，存入现有 preferences 表，旧安装缺失键时默认开启。分类切换、符号页空格、退格、回车及主键盘标点不走自动返回回调；emoji 点击仍保持面板，允许连续输入，不读取此开关。

平台 `commitText()` 返回 true 只表示调用被接受，不能据此保证任意宿主最终落字。拒绝提交或连接为空不会触发自动返回，但引擎状态仍没有完整回滚协议，见 G01。

### 空格标签与常用标点（0.3.1）

`spaceButton(showLanguage)` 显式区分显示场景：`renderKeyboard()` 传 `true`，显示“␣＋当前语言”；`renderSymbols()` 传 `false`，只显示“␣”，同时不附加语言 `stateDescription`。两处都保留“空格”无障碍名称并调用既有 `space()`，不因标签差异改变输入。emoji 五笔搜索复用主键盘时也显示语言；主键盘空格长按光标控制保持。

三种语言的逗号、句号均通过 `Ui.punctuationButton()` 创建。0.4.2 修订后：关闭顶部数字行时，中文长按分别输入全角“！”“？”，英文/韩语为半角 `!`、`?`；开启时中文为“：”“？”，英文/韩语为 `:`、`?`。英韩单个直双引号仅在数字行开启时位于逗号左侧功能键右上角及长按，英文保留短按拼写切换，韩语短按无操作、隐藏数字行后仍禁用。中文成对引号位于简/繁键右上角提示与长按，与数字行无关。短按均保持原标点。标点键帽采用“长按符号在上、短按符号在下”，上行较小且使用淡色，短按主符号保持原字号。`contentDescription` 仍为原标点，`stateDescription` 说明长按输出；`OnLongClickListener` 返回 `true`，由 Android Button 消费长按并抑制松手后的短按，不使用自建定时器或重复提交逻辑。

短按和长按均通过服务的 `punct()` 进入当前引擎：有五笔候选先确认首选，无匹配保留编码并提示；英文和韩语先确认原预编辑再追加标点；搜索模式写入 `emojiQuery`，不直接写宿主正文。符号页网格中的符号仍直接选择，快捷键用于三种语言主键盘及复用该键盘的五笔搜索。

搜索时五笔使用简体候选，不覆盖服务原有简繁选择。空格、回车和选字形成搜索关键词；只有明确点击 emoji 才向宿主提交 emoji。`insertEmoji()` 先排队重置五笔引擎，再校验会话、提交 emoji，成功且非隐私时记次数；保留当前网格实例与顺序，避免手指下条目换位。

浏览页每页 30 项；搜索每页 12 项；常用只保留最多 30 项、固定一页。`EmojiRanking` 按使用次数、最近顺序、默认种子顺序和原始顺序排序，先过滤不支持字形再填满。未使用的肤色变体不参与默认补位，使用过后可以进入常用；分类和搜索仍可显示变体。

字形能力用 `TextPaint.hasGlyph()` 检测，结果放 `glyphCache`，服务生命周期内复用。分类横向位置在重绘前读取，`EmojiCategoryStrip` 在首次布局后恢复；回调还检查分类条实例身份，旧 View 的通知不能覆盖新位置。切面板或失效会话重置分类条位置。

## 剪贴板显示与按键事件

当前内容默认预览最多 1,500 个 UTF-16 单元，展开最多 100,000，粘贴仍使用全文。历史预览每项最多取 1,000 单元、显示三行，粘贴也是全文；这些显示截取不能复用于实际输入。内容变化重置 `clipboardRevealed/clipboardExpanded`；隐私与持久化规则见 [数据与隐私](DATA_AND_PRIVACY.md)。

退格长按在 420ms 后启动，之后每 85ms 重复。触摸观察器返回 `false`，保留 Button 正常点击和无障碍 `performClick()` 通道；松手、取消、重绘、会话失效均取消重复任务。不要让触摸观察器吞掉所有点击。

0.4.1 轻震动由 `HapticFeedback` 统一映射，默认强度 50%、范围 0–100%。有振幅控制时固定 10ms，振幅按百分比映射到 1–255；无振幅控制时默认振幅配 1–20ms 短脉冲，50% 为 10ms。0% 或无振动硬件不构造效果。服务在 readSettings 中缓存 VibrationEffect，按键只播放缓存，保留至少 30ms 间隔；这是触感限制，不参与输入节流。

## 弹层与界面约束

长按地球打开语言列表，顺序来自 `InputLanguage.entries`，固定 English、五笔86、한국어。打开、取消或选择当前项不确认原输入；选择其他项才 resolve。新输入、重绘和会话失效关闭列表，返回键优先关闭语言列表。

字根卡片仅在五笔、非密码且 `roots=true` 时响应 A～Y 长按。用专用字体显示字根 JSON 的全部形态，长按返回 `true`，不提交字母。两类 PopupWindow 都以可见屏幕范围限制位置，尽量显示在锚点上方，不抢占输入焦点；重构时要保留横竖屏及 RTL 边界处理。

2026-11-10 的同版本修正仅涉及 B/L/O/P 数据：L 恢复田、补力和繁体車，O 恢复火，两键移除误提取的 `{`；B 补耳；P 补“礻去末点／衤去末两笔”的共同形态。P 的非成字根使用专用字体 U+E000，保留首点，无障碍名称明确说明笔形；不把完整礻、衤当作该根。当前 25 键共 262 项，其他 21 键的列表及现有字形轮廓保持。重建与校正来源见 [数据与隐私](DATA_AND_PRIVACY.md)，本次验收状态见 [0.3.3 修正补记](../validation/VALIDATION-0.3.3.md#2026-11-10-字根修正补记)。

按键 tag、`contentDescription`、`stateDescription` 同时用于可访问性和仪器测试定位。图标更换要同步语义；显示读音、简繁、英文开关和韩语 Shift 状态要与实际状态一致。新增按钮优先复用 `Ui` 和现有矢量图标方式，不在 UI 点击回调里另写一条宿主提交链路。

## 0.4.0 五笔词频设置与独立清空

输入习惯增加“**五笔按本地词频排序**”，新旧安装默认开启，未知值回退开启。关闭恢复旧固定查询与排序并停止计分，记录保留；服务在输入生命周期读取。候选样式、单行/展开、点击重新核对和读音展示不变，当前显示期间不会因计分反馈换位。

隐私与数据说明明确学习只在本机、最多两万条、隐藏后批保存，无整段输入历史。原联合清空拆为三个按钮，独立说明和确认；完成提示来自后台实际结果，失败提示重试。清词频保持开关；清短语仅清随之失效的学习，清 emoji 不动五笔。设置和剪贴板保留。短语管理单条删除也走同一后台流程。

日常词频保存依据 IME 窗口真实隐藏，不依据退出某面板、打开某个设置控件或仅结束输入框；没有轮询/定时任务。此前输入的候选如果在打开设置前被 resolve 并由宿主接受，按正常正文提交计分，内部 emoji 搜索不计分。详细身份和清空边界见 [词频维护说明](WUBI_FREQUENCY.md)。

## 0.4.1 轻震动强度与关于页

“按键轻震动”保持默认关闭，其后为“振动强度”SeekBar 和百分比标签。开关关闭禁用滑动条但保留值，开启后可拖动；范围 0–100%，默认 50%，0% 标签明确为不振动。拖动只改内存显示，松手才写入 `haptic_strength` 并预览一次；无障碍 ACTION_SET_PROGRESS/方向键没有触摸结束回调，因此每次用户单步调整保存并预览，程序初始化/重建不触发保存或振动。没有周期任务、拖动逐帧数据库写入或逐帧预览。

预览与键盘共用 [HapticFeedback.kt](../../app/src/main/java/com/fanson/ime/keyboard/HapticFeedback.kt)。服务在原 onStartInput/onStartInputView 读取开关和强度，缓存硬件能力对应的效果；不修改三语输入链路。旧安装缺少强度时使用 50%，保留原开关；旧版系统 DEFAULT_AMPLITUDE 与新的 50% 不保证感受相同。不同硬件可能无法呈现每一级差异，手机实际触感和系统限制仍需用户验收。

关于页增加可选择复制的 `作者邮箱：cnxfs@foxmail.com`，不配置发送动作，不新增网络权限或外部邮件调用。API 依据：[振幅能力](https://developer.android.com/reference/android/os/Vibrator#hasAmplitudeControl())、[单次效果参数](https://developer.android.com/reference/android/os/VibrationEffect#createOneShot(long,int))；仅参考平台契约，未引入第三方代码或依赖。

2026-11-12 在邮箱下按 Gitee、GitHub 顺序增加两个独立 TextView，显示用户提供的完整 HTTPS 地址。复用 `Ui.text` 和主题 accent 链接颜色，通过平台 `Linkify.WEB_URLS` 生成 URLSpan 并启用原生链接点击；由系统 ACTION_VIEW 交给浏览器，不内嵌 WebView、不添加 INTERNET 权限、不读取或附带输入内容。邮箱可选择复制的行为保持。验证见 [链接补记](../validation/VALIDATION-0.4.2.md#2026-11-12-项目链接与提交)。

## 0.4.2 英语 Shift 和撇号

英语 Shift 三个矢量图标分别为 ic_shift、ic_shift_auto、ic_caps，配合状态说明区分小写、句首自动大写和手动持续大写。自动状态输入一个字母后立即恢复小写键帽；点按取消当前词自动大写，支持退格删空保持。设置“英语句首自动大写”默认开启，独立于拼写。英语 L 使用 cornerHintButton 在右上角独立绘制灰色撇号，恢复普通单行字母基线，短按依然传字母，长按只传撇号，不追加 l。韩语和五笔键位/长按保持。完整规则见 [英语维护说明](ENGLISH_INPUT.md)，验收见 [0.4.2 验证](../validation/VALIDATION-0.4.2.md)。

## 0.4.2 同版本长按修订

顶部数字行长按以 PC !@#$%^&*() 为基础，中文 1/9/0 改为 ！/（/），英语/韩语保持半角。数字、L 和三语左侧功能键角标复用 `CornerHintButton`，不挤动主文字；`Ui.iconButton` 可选角标共用该入口，保留原图标/强调色。句号长按始终为对应语言问号；英韩功能键引号仅随数字行开启，中文简/繁成对引号与数字行无关。中文成对引号使用原成功提交回调，核对光标前一个右引号后移动到中间；搜索只改内部关键词。布局、映射、UTF-16 位置与失败处理详见 [长按维护说明](KEYBOARD_SHORTCUTS.md)。
