# 待改进事项与验证缺口

基于 2026-11-09 的 0.3.0 源码检查整理。这里区分实现限制与可优化结构，不表示已发生用户故障，也不表示本次已经修复。优先级为后续工作建议：先处理提交与隐私语义，再调整维护结构和性能；具体范围由后续任务确定。

## 输入正确性与隐私边界

| 编号 | 源码事实与影响 | 后续变更前需要明确/验证 |
| --- | --- | --- |
| G01 | 普通输入先推进引擎状态，再应用宿主编辑；`commitText()` 的失败通常没有传播回引擎。连接为空或宿主拒绝提交时，没有完整回滚/重放协议。emoji 次数和符号自动返回已检查平台提交返回值，仍不等于宿主实际落字或引擎回滚 | 明确部分成功、连接丢失、会话结束后的语义；用可控失败的编辑器验证不重复提交、不写入下一输入框 |
| G02 | `privateField` 包含 NO_PERSONALIZED_LEARNING；但英文补全关闭、候选隐藏、字根和 emoji 入口限制主要依据 `password`。非密码隐私字段仍可使用离线补全/emoji，但不更新 emoji 次数或自动记录剪贴板 | 与产品要求核对“禁止持久化”和“禁止展示建议”的区别，再决定是否收紧；补专用 EditorInfo/仪器测试，不先声称现有策略完全覆盖设计稿 |
| G03 | `onUpdateSelection()` 仅清理英文/韩语预编辑；五笔未在光标变更时清码。同会话异步任务依赖 FIFO，没有单独查询版本或连接快照 | 明确五笔移动光标的期望，以及排队输入遇到语言/面板/输入框切换的语义；新增快打和切换压力用例；不能简单丢弃含正文提交的旧结果 |
| G04 | 剪贴板监听跟随服务生命周期；`onFinishInput()` 清除隐私标志。隐私编辑结束后、默认 IME 服务仍运行时的复制会按普通后台复制处理 | 明确会话结束后的隐私保护时限和产品预期；用合成数据验证锁屏、面板外、隐藏键盘、隐私结束等边界 |

## 文档偏差的处理

`DESIGN.md` 的历史修订含早期设想，例如可回收列表、数据库候选分页、独立查询序号、单独隐私包和自动短语取码；这些不能当作当前架构。现行技术文档已按源码区分。产品原稿与版本验证记录保留历史语境，当前规则变更时同步技术章节。

关闭某项时写明对应变更、实际验证和仍存在的边界，再更新架构/输入/数据等正文；不要只删掉该行，让实现决策再次失去记录。

## 0.4.0 五笔学习的已知边界

词频参数是经验初值；主动和自动首选均加 1，可能强化已有首选，未实现纠错扣分或差异权重。64 个补回来源为性能边界，不做无界词典排序；大量手动短语的界面成本仍存在。时间人为大幅修改会影响遗忘，未隐藏或保存前进程被杀允许丢失学习。词频初始化失败时当前服务回退固定排序，无周期重试。模拟器性能仅为本次测量，用户已确认手机功能生效，长期流畅度、耗电、习惯适配及端到端耗时仍需观察与测量；详见 [维护说明](WUBI_FREQUENCY.md) 和 [本版记录](../validation/VALIDATION-0.4.0.md)。

## 0.4.2 英语句首与缩写的已知边界

句首以宿主/Android getCursorCapsMode 的返回为准，0/不支持时保守小写；兼容段首返回 CAP_WORDS 的平台行为。缩写句点（例如 Dr.）、非英文标点及特殊编辑器语法不保证准确识别，不做整句语法推断。静态缩写只有明确列出的 32 项，its 等歧义原词保留第二，不用空格强制纠正；were/well/ill 等暂不映射。同步边界查询在不同宿主中的延迟、长时间体验及电量仍需观察，不宣称已经量化。英语位置预测补充自身/外部回调识别，不解决 G01 的宿主提交失败回滚问题，也不扩大为五笔光标状态重构。详见 [维护说明](ENGLISH_INPUT.md) 与 [0.4.2 实际验证](../validation/VALIDATION-0.4.2.md)。

0.4.2 同版本中文成对引号依赖宿主允许读取刚插入的一个右引号及 setSelection；拒绝或返回未知 offset 时不猜测移动，可能停在引号后。空文本、正文中间、选区替换与 UTF-16 代理对前文已加入专项回归；不同实际宿主仍待用户验收。L 裁切修复验证最小 40dp、1.0/1.3 字体比例及深浅主题，不声称覆盖所有极端系统字体/厂商样式。详见 [长按维护](KEYBOARD_SHORTCUTS.md)。
