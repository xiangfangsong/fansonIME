## 本版行为

- 中文、英文主键盘顶部新增 1～9、0 数字行，默认开启；“键盘外观 → 显示顶部数字行”可关闭，设置持久保存，两种模式共用。
- 移除 Q～P 长按输入数字。字根提示关闭时不注册长按查字根；开启后五笔键帽保留简要字根，长按 A～Y 展示对应完整字根卡片，英文及密码输入不启用。
- 卡片展示 25 个键位、258 个基本及变形字根，内置 82,996 字节专用字体子集。特殊形状使用上游修改后的字形，普通字体不参与字根网格显示；来源、固定 revision、校验值、ARPHIC 字体许可和修改声明随项目及 APK 保留。
- 卡片显示在按键上方并限制在屏幕内；松手保留，关闭按钮、外部点击或继续输入可关闭，查看不提交编码、不改变正文。输入会话和面板变化时释放弹层。
- 五笔原 Z 键改为“音＋放大镜”本地矢量图标，暂不实现拼音反查，点击仅提示暂未开放；英文 Z/z 输入保持正常。
