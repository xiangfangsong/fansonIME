## 本版行为

- 主键盘空闲时只显示功能按钮行；有待处理五笔编码或英文补全词时只显示候选行，编码提示并入候选行左侧。两种状态均为 44dp，顶部不再有独立编码提示行，切换不改变主键盘高度。
- 选词、提交、清码或退格删完后恢复功能按钮；英文关闭自动拼写和密码输入时持续显示按钮。无匹配时保留编码及单行修正提示。辅助页面保留按钮、隐藏候选，emoji 搜索有编码时切换候选。
- 设置页移除顶部“放松 / 个人输入法”，副标题按用户指定改为“全部离线 · 自己撑控”；版本仍为 0.1.9。
- 数字页左下角改为“返回”，返回原来的中文或英文主键盘模式。
- 第三行末列为 `*`，第四行末列为 `/`，运算符列从上到下为 `+ - * /`。
- 底行依次为“返回、_、退格、回车”，下划线与上方 0 键对齐。
- 按用户补充要求先核查字库。本版不增加 CJK 开关、扩展码表或候选字体，原字库及候选排序保持。

当前码表使用 Unicode 文字，不受 GBK 范围限制。逐个使用 Python 标准 `gbk` 编码器验证，20,924 个单字可用 GBK 编码，49,467 个不能。已查得 `𠮷`（U+20BB7）编码为 `fkf`，`𠀀`（U+20000）编码为 `ghab`；这些生僻字无需新增扩展库即可查询。

原字库尚未覆盖所有较新的 CJK 扩展区，但用户要求暂不扩展；后续可根据实际缺字再决定补充范围。码表能查到汉字与当前设备、目标应用能显示字形是不同事项。
