## 本版行为

- 五笔86有待提交编码时，回车提交原始字母，不选候选、不附加换行、不发送；同一编码下空格仍选首选。无编码时回车遵循编辑器动作，普通换行显示矢量回折箭头。
- Shift：五笔86 → 英文大写 → 英文小写；之后切换英文大小写，模式按钮可返回五笔86。待提交编码在 Shift 切入英文时提交为原始字母。
- 自有界面统一“五笔86”；系统不再单独注册该子类型，选择页仅显示“放松输入法”。
- 工具栏为模式、剪贴板、符号、emoji、设置和收起；功能键使用本地矢量图标，收起为设置右侧的向下三角，保留无障碍说明。删除底部切换输入法与收起行。
- 修复销毁输入法服务时系统结束输入回调向已关闭执行器提交任务造成的异常，并覆盖切换离开后重新绑定的场景。
